# 项目名称：AI 动态炼金术工坊 (Alchemy Forge)

## 1. 项目目标与核心机制
使用现代前端技术（推荐 React + TypeScript + Tailwind CSS）构建一款拖拽式炼金合成模拟器。
- **核心交互**：工作区（Workspace）内悬浮显示“元素卡”（含 SVG 图标 + 元素名称）。用户拖拽一张卡至另一张卡上触发合成。
- **AI 驱动**：合成结果优先查询本地配方书（Recipe Book）；若无匹配，则调用 OpenAI API（用户需在界面输入 Endpoint 和 Key）通过**工具调用（Function Calling）**动态生成结果。
- **动态扩展**：AI 既可引用已有元素，也可即时创造全新元素，并自动生成对应的合成配方。

## 2. 数据模型 (Data Models)
- **元素 (Element)**：`{ id: string (uuid), name: string, svg: string (SVG代码) }`
- **合成配方 (Recipe)**：`{ id: string, inputA: string (元素ID), inputB: string (元素ID), outputs: string[] (元素ID数组, 长度1-3) }`
- **工作区 (Workspace)**：包含 `elements: Element[]` 和 `recipes: Recipe[]` 的完整状态快照。

## 3. 详细功能逻辑

### 3.1 初始状态与工作区管理
- **默认开局**：新建 Workspace 时，仅预置 **水、火、风、土** 四种基础元素（SVG 可由您设计通用占位符），配方书为空。
- **全局管理**：Workspace 作为顶层状态容器，所有元素和配方归属当前 Workspace。
- **导入/导出**：支持将当前 Workspace 的所有数据（元素+配方）打包为 **.zip 文件**（内含 manifest.json），支持用户分享给他人并一键导入覆写当前工作区。

### 3.2 合成流程（严格顺序）
当用户将元素 A 拖拽至元素 B 上时，执行以下判定：

1. **查重（本地优先）**：
   - 检查 `recipes` 中是否存在 `(inputA=A.id && inputB=B.id)` 或 `(inputA=B.id && inputB=A.id)` 的条目。
   - **若存在**：直接执行该配方，将 `outputs` 中的所有元素实例添加到工作区（如元素已存在则跳过，仅显示获得提示）。
   - **若不存在**：进入 AI 生成流程（步骤 2）。

2. **AI 生成（LLM 调用）**：
   - **上下文构造**：系统提示词需注入当前 Workspace 内 **全部已有元素列表** 和 **所有涉及 A、B 元素的现有配方**（防止生成重复或冲突的内容）。
   - **工具强制调用**：LLM 必须按顺序或并行调用以下两个工具（Function Calling）：
     - **Tool 1: `craft_elements`**：用于创建合成过程中产生的新元素（若合成结果为已有元素，则无需调用此工具）。
       - *参数*：`new_elements` (数组, 包含 `name` 和 `svg_content`)。
     - **Tool 2: `craft_recipe`**：用于建立本次合成的配方表。
       - *参数*：`output_element_ids` (数组, 引用已有元素ID或刚创建的新元素ID，数量 1~3)。
   - **数据持久化**：前端解析工具调用响应，**先**保存新元素（生成 UUID），**再**保存包含输入对和新输出 ID 的配方至本地 Recipe Book。最后执行合成动画。

### 3.3 配方书 (Recipe Book)
- 界面侧边栏展示当前 Workspace 下所有已解锁的配方。
- 条目格式：`[输入A] + [输入B] = [输出1], [输出2]...`，配以元素图标，方便玩家复盘。


### 3.4 元素列表与工作区操作增强
- **元素总览按钮**：在工作区工具栏上固定显示“元素列表”按钮（图标 + 文字）。点击后弹出一个模态框/侧滑面板，以网格或列表形式展示当前 Workspace 内 **全部已解锁元素**（含 SVG 图标和名称）。
- **添加元素至工作区**：在元素列表模态框中，每个元素卡片右侧/下方提供“添加到工作区”按钮（或直接单击卡片）。点击后，该元素的 **一个副本** 会出现在工作区随机位置（若工作区已有相同元素，则数量 +1，不覆盖）。
- **快速复制元素**：在工作区中，**双击**任意元素卡，该元素将立即在工作区生成一份完全相同的副本（ID 相同，位置偏移 20px 以防重叠）。此操作无需消耗任何资源，旨在方便玩家进行批量合成实验。
- **元素列表排序与筛选**：支持按名称字母序、创建时间、使用频率（被合成次数）排序，并提供搜索框快速过滤元素。

## 4. 技术实现约束与 LLM 交互规范

### 4.1 前端环境
- 拖拽实现：使用 `@dnd-kit/core` 或 `react-beautiful-dnd` 处理卡片拖拽叠放事件。
- AI 客户端：封装 OpenAI 标准 API 调用，支持用户自定义 `baseURL` 和 `API Key`，请求时携带当前 Workspace 上下文。

### 4.2 LLM 系统提示词模板（固定前缀）
```text
你是一个炼金术合成规则生成器。当前世界拥有以下元素：[这里注入元素列表]。玩家正尝试合成 [元素A] 和 [元素B]。
请根据化学、物理或神话隐喻，生成 1 到 3 种合成产物。
规则：
1. 如果产物是已有元素，请直接引用其 ID。
2. 如果产物是全新的，请调用 craft_elements 创建它，并设计一个极简、抽象、美观的 SVG（画布 100x100，纯矢量）。
3. 必须调用 craft_recipe 绑定本次的输入和输出。
注意：不要生成与输入元素完全相同的产物，不要生成过于复杂或不合理的 SVG。


### 4.3 Function Calling 完整 Schema（需后端/前端严格适配）
```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "craft_elements",
        "description": "创建本次合成中出现的新元素",
        "parameters": {
          "type": "object",
          "properties": {
            "new_elements": {
              "type": "array",
              "items": {
                "type": "object",
                "properties": {
                  "name": { "type": "string" },
                  "svg_content": { "type": "string" }
                },
                "required": ["name", "svg_content"]
              }
            }
          },
          "required": ["new_elements"]
        }
      }
    },
    {
      "type": "function",
      "function": {
        "name": "craft_recipe",
        "description": "记录本次双输入合成产生的输出结果ID",
        "parameters": {
          "type": "object",
          "properties": {
            "output_element_ids": {
              "type": "array",
              "items": { "type": "string" },
              "minItems": 1,
              "maxItems": 3,
              "description": "必须是已有元素ID或刚通过craft_elements创建的元素ID"
            }
          },
          "required": ["output_element_ids"]
        }
      }
    }
  ],
  "tool_choice": "auto"
}
```

## 5. 异常处理与用户体验
- **AI 调用失败**：网络超时或 Key 无效时，弹窗提示“炼金术失灵，请检查 API 配置”，不改变现有工作区。
- **元素重名**：当 AI 生成与已有元素重名的元素时，前端自动在 ID 层面区分（新 UUID），显示名称后追加 `(异界)` 后缀以示区分。
- **合成动画**：拖拽合成时，两张卡片叠加闪烁，调用 API 期间显示“贤者之石充能中...”加载态。
```
## 6. 整体 UI/UX 易用性补充
- **拖拽引导**：首次打开工作区时，显示半透明提示浮层“拖拽一张卡片到另一张上即可炼金”，并配有箭头动画，3 秒后自动消失。
- ui/ux响应式适配：让这个能适配不同的操作设备和屏幕大小，包括在移动端也可以很轻松地玩。
- **合成反馈强化**：
  - 拖拽过程中，目标卡片高亮放大，松开时触发闪烁效果。
  - AI 请求期间，在屏幕中央显示“贤者之石充能中...”的加载弹窗，并附带进度条动效，防止用户重复拖拽。
  - 合成成功后，在工作区顶部弹出 Toast 通知，显示“获得：[元素名1]、[元素名2]...”，并伴有元素图标飘落动画。
- **撤销与重做**：提供简单的撤销/重做按钮（至少缓存最近 5 步操作），用于误删除或误合成后的恢复。
- **键盘快捷键**：
  - `Ctrl/Cmd + K`：快速打开元素列表。
  - `Delete` 或 `Backspace`：选中工作区卡片后删除该元素（需二次确认）。
- **响应式布局**：工作区卡片尺寸自适应屏幕，移动端支持长按拖拽（利用 `touch` 事件），确保平板和手机也能流畅游玩。
